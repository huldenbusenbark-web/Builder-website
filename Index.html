Skidware Builder · local toolkit

Build lab malware payloads in the browser

Skidware Builder is a single-page toolkit that generates Python payload source for research and lab environments. Pick a module, tune options (C2, Discord webhooks, stealth, persistence), choose output formats, then copy or download the code. Everything runs client-side in your browser — no account, no server-side build pipeline.

KeyloggerBuffered capture, window titles, clipboard, encrypted flush, webhooks.
InfostealerModular harvest: tokens, browsers, Telegram, Steam, WiFi, files.
Backdoor / MalwareReverse/bind shells, anti-analysis stubs, persistence hooks.
PhishingBrand kits (Roblox, Outlook, Google, TikTok, GitHub, GitLab, Facebook, Snapchat, zyo.lol, feds.lol) + collector.
Mac implantLaunchAgents, login items, keychain/browser inventory.
Ransomware labEncrypt/decrypt modes, notes, extension filters, key export.

Intended for authorized testing on systems you own or have permission to assess. Generated samples are source code you run yourself. Outputs: .py, .html, .pyi, .pyc helper, .exe stub.
